# Devansh Mishra Portfolio

A responsive Next.js conversion of the supplied Salesforce Trailblazer portfolio designs. It keeps the original black, acid-green, pink, purple, and Salesforce-blue visual language, with routes for work, community, and contact.

The site opens in dark mode. Use the sun/moon control in the navigation to switch themes; your choice is saved in this browser.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Create a production build with `npm run build`, then serve it with `npm start`.

## Deploy

The project is ready for Vercel: import the repository, keep the default Next.js build settings, and deploy. It can also be hosted on any Node.js platform that supports Next.js. No environment variables or external services are required.

## Profile details

Portfolio copy and experience are based on the supplied profile. The interactive 3D LinkedIn card uses the supplied portrait and QR code. Update profile links and details in `lib/profile.ts`.
